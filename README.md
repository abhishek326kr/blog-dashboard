# Blogging Dashboard

A **powerful and efficient** blogging dashboard built using **Core PHP** for backend and **React (via CDN)** for frontend rendering. This dashboard is designed to manage blog posts, SEO settings, user authentication, media uploads, and more!

---

## 🚀 Features

✅ **Blog Management** - Create, edit, delete blog posts  
✅ **SEO Optimization** - Manage meta tags for better search ranking  
✅ **User Authentication** - Secure login system with role-based access  
✅ **Rich Text Editor** - WYSIWYG editor for easy blog writing  
✅ **Media Management** - Upload and manage images & other media  
✅ **Dashboard Analytics** - Track blog performance with charts  
✅ **Responsive Design** - Mobile-friendly UI with Bootstrap  
✅ **Role-Based Access Control** - Different permissions for admins, editors, and users  
✅ **Notifications** - Email alerts for blog updates & submissions  

---

## 🛠️ Tech Stack

- **Backend:** PHP (Core PHP, MySQL for database)
- **Frontend:** React (via CDN), Bootstrap
- **Hosting:** Hostinger Cloud Hosting
- **Editor:** CKEditor / TinyMCE for blog editing
- **APIs:** Integrated for SEO & analytics tracking

---

## 📌 Installation & Setup

1️⃣ **Clone the repository**
```sh
git clone https://github.com/your-username/blogging-dashboard.git
cd blogging-dashboard
```

2️⃣ **Set up the database**
- Import `database.sql` file into MySQL.
- Configure `config.php` with your database credentials.

3️⃣ **Start the server**
```sh
php -S localhost:8000
```

4️⃣ **Open in Browser**
```
http://localhost:8000/dashboard.php
```
